EcoRide — App Android TFG
Proyecto Final de Grado · Android · 2026
Aplicación Android completa para el alquiler de patinetes eléctricos. Arquitectura MVVM con Jetpack Compose, caché offline con Room y autenticación JWT persistida. Incluye backend REST en Flask con endpoints para usuarios, vehículos y alquileres.
  • Autenticación JWT persistida con DataStore entre sesiones
  • Caché local con Room — funciona sin conexión a internet
  • Navegación completa: Login → Lista de patinetes → Detalle → Historial
  • StateFlow + ViewModel que sobrevive rotaciones de pantalla
  • Backend Flask con API REST documentada y credenciales de prueba
Kotlin Jetpack Compose MVVM Retrofit Room DB DataStore Coroutines Material 3 Flask Python Android Studio

AirTrack RFID — Control de Equipaje
Sistema de Trazabilidad · Full Stack · 2026
Sistema completo de trazabilidad de maletas y cajas en aeropuerto mediante RFID. Arquitectura containerizada con Docker Compose: FastAPI + PostgreSQL + Keycloak para autenticación OAuth2/OpenID + Nginx como reverse proxy. Integración con pistola lectora Android HT518-R501.
  • API REST completa con 15+ endpoints para scans, vuelos y ubicaciones
  • Autenticación robusta con Keycloak (roles: admin, operator, viewer)
  • Soporte batch offline — sincroniza lecturas RFID acumuladas
  • Dashboard con estadísticas en tiempo real y gestión de incidencias
  • Despliegue con un solo comando: docker compose up --build
FastAPI Python Docker PostgreSQL Keycloak OAuth2 Nginx Bulma CSS RFID Android REST API
